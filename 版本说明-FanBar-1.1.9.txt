FanBar Pro 1.1.9 (build 119) 版本说明
2026-11-15 七项意见交付（arm64）
================================================================================

版本：1.1.8 / 118 → 1.1.9 / 119；Bundle ID（local.fanbar.app）、
最低系统版本（15.8）不变。全包（app + helper + CLI + Diagnostics +
Widget + Sparkle 等嵌套组件）均由本机自签证书 Local QA Code Signing 签名。
本版采用完整源码重建（Xcode 27.2 / Swift 6.4.2，scripts/package-app.sh），
沿用 1.1.8 的构建链；内嵌源码包同步更名为
FanBar-Pro-1.1.9-源码与Xcode工程.zip。

--------------------------------------------------------------------------------
二、菜单栏动画 / 面板动画（两个独立开关 + 低电量模式硬约束）
--------------------------------------------------------------------------------
· 设置 → 菜单栏 → 动画：菜单栏状态项图标随风扇转速旋转（复用
  MenuBarIconAnimator / MenuBarIconRotor / SwitchFeedbackPreferences）。
· 设置 → 面板 → 动画：面板内风扇转子与过渡（复用 PanelAnimationPreferences，
  接通 FanMenu / FanMenuSections 三处动画门）。
· 内置硬约束（不可配置）：系统开启「低电量模式」时两个动画自动暂停，
  关闭后自动恢复。实现：ProcessInfo.processInfo.isLowPowerModeEnabled +
  NSNotification.Name.NSProcessInfoPowerStateDidChange（实际 API 已编译验证），
  Sources/FanBar/LowPowerMode.swift 的 LowPowerMode / LowPowerModeMonitor，
  启动时读一次、运行中监听变化；无法取得状态按「不暂停」处理（不误伤）。
  无关闭该约束的开关，也没有把低电量模式做成用户可配置项。

--------------------------------------------------------------------------------
四、菜单栏显示内容新增「曲线模式」
--------------------------------------------------------------------------------
· MenuBarDisplayMode 新增 .curveMode（中文名「曲线模式」），出现在
  设置 → 菜单栏 → 显示内容 的选项里。
· 显示 = 风扇图标 + 当前曲线模式图标（两个独立 NSStatusItem）。
  模式取值：静谧 / 均衡 / 性能 / 极速 / 固定 / 自定义…，
  每一档都有独立 SF Symbol 图标，切换档位图标随之变化。
  真实映射：FanCoolingPreset 只有 4 个 case（silent/balanced/performance/
  extreme，rawValue 0…3）；「固定」来自 FanController.Mode.fixed(Int)，
  「自定义…」来自 CoolingPresetID.custom(UUID)，二者并非该枚举的 case。
· 两个图标是两个独立 NSStatusItem（不是同一 item 里画两个图）：标准
  NSStatusBarButton、设置 autosaveName、不设 behavior、不设自定义 view，
  因此 macOS 原生 ⌘ + 拖拽 可分别调整位置/间距。
  Sources/FanBar/CurveModeStatusItem.swift；LegacyStatusItemController 接线。
· 曲线状态项菜单的「自定义…」复用既有曲线自定义界面
  （设置 → 散热 → FanCurveEditorView）。

六、卡巴斯基风格安装器 / 卸载器 + 安装期自动注册两个服务
--------------------------------------------------------------------------------
· DMG 根目录仅 安装FanBarPro.app + 卸载FanBarPro.app，主程序
  FanBar Pro.app 内嵌在 安装FanBarPro.app/Contents/Resources/Payload/。
· 安装器提权一次，装到 /Applications/FanBar Pro.app；安装期间直接以 root
  注册两项服务（用户无需再到设置里操作）：
    1) 后台风扇监控 Helper：沿用 LegacyHelperDaemon.installCommand 的
       LegacyLaunchd 路径（拷 helper 到 /Library/PrivilegedHelperTools/、
       写 /Library/LaunchDaemons/local.fanbar.helper.plist、
       codesign --verify --strict -R 校验、launchctl enable/bootstrap system），
       本机自签无 Team ID，故不调用 SMAppService。
    2) 开机 Daemon 冷启动守护：安装
       /Library/LaunchDaemons/local.fanbar.coldstart.plist 与
       /Library/Application Support/FanBar/fanbar-coldstart.sh，
       plutil -lint + bash -n 校验后 launchctl enable/bootout/bootstrap system。
       行为保持 1.1.8：开机 30/60/90 秒三次 kickstart -k，插电/台式机顺带
       「均衡」，电池 MacBook 不改曲线，90 秒后本次开机不再拉起。
· 卸载器反向清理（先 bootout 再删）：helper plist、PrivilegedHelperTools、
  coldstart plist、fanbar-coldstart.sh、/Library/Logs/FanBar-ColdStart*、
  /Applications/FanBar Pro.app，以及工程真实使用的偏好/缓存；
  恒以「✓ 没有残留」+ exit 0 收尾，仅用户取消回欢迎页，永不显示卸载失败。
· 保留 冷启动加强.command 与设置 → 通用 → 命令行与自动化的加载/卸载开关。
