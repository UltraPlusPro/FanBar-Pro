FanBar Pro 1.1.11 (build 121) 版本说明
2026-11-15 两项意见交付；2026-11-16 追加：DMG 内附源码与 Xcode 工程（arm64）
================================================================================

版本：1.1.10 / 120 → 1.1.11 / 121；Bundle ID（local.fanbar.app）、
最低系统版本（15.8）不变。全包（app + helper + CLI + Diagnostics +
Widget + Sparkle 等嵌套组件）均由本机自签证书 Local QA Code Signing 签名。
本版为完整源码重建（scripts/package-app.sh，含签名审计门禁）。

--------------------------------------------------------------------------------
一、记录设置 → 高级 → 保留：新增「2 天」
--------------------------------------------------------------------------------
· TemperatureLogPreferences.retentionOptions 由 [7, 30, 90, 0] 改为
  [2, 7, 30, 90, 0]：档位仍按「从短到长、永久垫底」排列，默认值仍是 30 天，
  已存过的 7 / 30 / 90 / 永久原样保留，升级用户不受影响。
· 选 2 天后：
  · 摘要与折叠行立刻显示「保留 2 天」（TemperatureLogText.retention 走
    「保留 %d 天」模板，无需新增文案）。
  · 同一行右侧的占用估算同步下调（TemperatureLogSizeEstimate 按保留天数折算，
    2 天的上限约为 7 天的 2/7），不会继续显示 7 天那一档的数字。
  · 清理时机不变：每次写入时每天最多清一次，切换档位会立刻触发一次
    （requestCleanup），所以改成 2 天不用等第二天才生效。
· 为什么是 2 天：CSV 按天分文件，2 天是「今天 + 昨天」都能留着的最短窗口，
  正好够回看一次偶发的风扇飙升，又不会让日志占着磁盘。

--------------------------------------------------------------------------------
二、曲线与温度 / 曲线与转速：下拉菜单补上「macOS」系统默认项
--------------------------------------------------------------------------------
· 1.1.10 里第二个菜单栏图标（曲线档位图标 + 读数）的下拉菜单只有 6 个曲线档位
  （静谧 / 均衡 / 性能 / 极速 / 固定 / 自定义…），没有把风扇交还 macOS 的入口，
  想回自动控制必须先点开风扇图标的面板。
· 1.1.11 给 CurveMode 增加 systemDefault 档，并排在 allCases 最前：
  · 菜单第 1 行 = 「macOS」（与主面板同名同图标
    arrow.triangle.2.circlepath），其下一条分隔线再列各曲线档位，
    最后一条分隔线后仍是「打开面板…」。
  · 点击它调用 FanController.setAutomatic()，与主面板「macOS」完全同一条路径。
  · 当前处于自动控制时，该项打勾；同时**菜单栏图标也变为 macOS 的循环箭头图标**
    —— 1.1.10 在自动控制下仍显示上一次的曲线档位图标，读起来像"还在跑曲线"。
  · 曲线档位图标与行为一律不变：固定仍按当前平均转速冻结、自定义…仍打开曲线编辑页。
· 兼容性：CurveMode 的 rawValue 只用于菜单内部回传，不落盘，
  因此新增档位不影响任何已存偏好。

--------------------------------------------------------------------------------
